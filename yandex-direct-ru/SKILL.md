# Яндекс.Директ - лучшие практики для российского рынка

## Структура кампаний (рекомендуемая)

| Тип кампании | Для чего | Особенности |
|--------------|----------|-------------|
| Поиск (Группа 1) | Горячий трафик | Точные и фразовые ключи |
| Поиск (Лиды) | Целевые конверсии | Оптимизация за цель |
| РСЯ | Ретаргетинг | Только на теплую аудиторию |
| МК (Мастер кампаний) | Тест | Только для старта, потом перевести в ручную |

## Ключевые правила работы с Директом

- **Не трогать** работающие конверсионные кампании без явной причины
- РСЯ для B2B/технических ниш часто даёт мусорный трафик - тестировать осторожно
- Автотаргетинг: включать на «Средне» - расширяет охват без большого мусора
- Минус-слова: добавлять максимально широкий список сразу при запуске

## Настройка счётчика Метрики

```
Обязательные цели для конверсионных кампаний:
- Отправка формы (submit event)
- Клик по телефону
- Клик по email
- Скролл ключевой страницы (75%)
- Клик на кнопку CTA
```

В Директе передавать ID счётчика с восклицательным знаком: `123456789!`

## Что работает в разных нишах

### Товары/оборудование (B2B)
- **Ключи**: "[бренд] купить", "[модель] цена", "[категория] производитель"
- **Минус**: "своими руками", "ремонт", "б/у", "схема", "характеристики" (info-запросы)
- **Посадочная**: конкретная страница товара/категории, НЕ главная
- **РСЯ**: работает для ретаргетинга, плохо для холодного трафика

### Услуги (B2C)
- **Ключи**: "[услуга] в [город]", "[проблема] решение"
- **Минус**: "отзывы", "форум", "своими руками", "бесплатно"
- **Посадочная**: лендинг с конкретным оффером + форма
- **РСЯ**: работает хорошо, особенно look-alike аудитории

### SaaS / веб-сервисы
- Акцент на Поиск, РСЯ для ретаргетинга
- Ключи по болям, не по фичам
- Трекать регистрацию + активацию как цели

## Диагностика "клики есть, конверсий нет"

1. Проверить посадочные страницы (правильный ли URL в объявлении?)
2. Проверить цели в Метрике (созданы ли JS-цели? работают ли?)
3. Проверить мобильную версию лендинга
4. Смотреть вебвизор на отказах - куда уходят пользователи
5. Реклама должна вести на конкретную страницу, не на главную
6. Проверить скорость загрузки страницы (PageSpeed > 50)

## Оптимизация ставок

```
Стратегии по приоритету:
1. Оптимизация конверсий (нужно 10+ конв/нед) - лучший результат
2. Ручное управление с корректировками - стартовая точка
3. Максимум кликов с ограничением - для тестов

НЕ использовать:
- Целевая доля рекламных расходов (ДРР) без данных об обороте в Метрике
- Недельный бюджет без настроенных целей
```

## Промо-статья как воронка (DIY альтернатива ПромоСтраницам)

Вместо дорогих ПромоСтраниц Яндекса (~50k₽/мес):
- Написать статью на своём сайте (SEO + конверсия)
- Запустить РСЯ на статью
- Цели: `article_read` (скролл 75%), `article_cta_click`
- Стоимость: только CPC, без абонентки

```
своими руками, сделать самому, своими силами,
ремонт, починить, сломан,
бесплатно, даром, скачать,

фото, картинки, видео,

схема, чертёж, характеристики
```

## Типичные ошибки при запуске

1. Запускать РСЯ сразу на холодную аудиторию в узких нишах
2. Вести трафик на главную страницу сайта
3. Не настроить цели в Метрике до запуска
4. Слишком широкие ключевые слова без минус-слов
5. Не добавить корректировки по устройствам (мобайл часто дороже конвертит)
